### N-4 — Required: `psql` rows cannot execute as written (X-E.3, X-E.22 ×2, D.1 smoke)

`kubectl -n atlas exec atlas-postgres-0 -- psql -U "$PGUSER" -d "$PGDATABASE" -Atf /dev/stdin < raw/data/rowcount.sql`: the quotes are consumed by the **operator's** shell, so `$PGUSER`/`$PGDATABASE` expand locally (unset → `psql -U '' -d ''`); the StatefulSet's env keys are `POSTGRES_USER`/`POSTGRES_DB` (A.0 L95, E.0.1 gets this right); and `kubectl exec` forwards stdin only with `-i`. Correct form for every occurrence: `kubectl -n <ns> exec -i atlas-postgres-0 -- sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Atf /dev/stdin' < raw/data/rowcount.sql`. Same fix in D.1's smoke column (`psql -U $PGUSER -d $PGDATABASE -c '\dt'`).
